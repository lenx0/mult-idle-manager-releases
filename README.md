# Multi Idle Manager — Downloads

Instaladores oficiais do **Multi Idle Manager** para Windows 10/11 (64 bits).

👉 **Baixe a versão mais recente em [Releases](https://github.com/lenx0/mult-idle-manager-releases/releases/latest)** ou pelo site **https://multidle.com.br**.

- O app é **gratuito** (até 2 jogos com 2 contas cada).
- O **Pro vitalício** é ativado dentro do app com o e-mail e o código do pedido da compra: https://multidle.com.br/#pricing
- O Windows pode exibir o aviso do SmartScreen em programas novos: clique em **Mais informações → Executar assim mesmo**.

Este repositório contém **apenas os instaladores** (sem código-fonte).
